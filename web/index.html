安全与用途说明

⚠️ 本工具仅在你有设备所有权时使用。签名密钥硬编码于家长管理 APK 中，公开已知。

接口列表：
· 拉取: GET http://parent-manage.readboy.com/api/v1/jpush/content?get_all=1
· 上传: POST https://parentadmin.readboy.com/v1/appinfo/controlApp/upload（Header 携带 control_list）
· 解绑: GET https://parentadmin.readboy.com/v1/machine/cancel_bindings（见 ZaralynUnbind）

签名算法：getSign2 = MD5(秒 + APPSECRET + MD5("parent-manage"))
getSign = uid + 秒 + MD5(秒 + APP_KEY + MD5("parentsadmin")) + "parentsadmin"

注意：浏览器直接 fetch 会遇到 CORS 限制，推荐复制 curl 命令在终端执行，或在服务器/VPS 上使用。
